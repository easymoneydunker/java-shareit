# Java-ShareIt  

**Java-ShareIt** — REST-сервис для краткосрочного шеринга вещей.  
Пользователи могут добавлять вещи, бронировать их, подтверждать или отклонять бронирования, искать вещи и создавать запросы. Проект построен с модульной структурой и ориентирован на масштабируемость и удобство использования.

## 🚀 Основные возможности  
- Добавление вещей пользователями для шеринга.  
- Создание бронирований вещей (запрос пользователя на аренду).  
- Подтверждение либо отклонение бронирований владельцем вещи.  
- Получение данных о бронированиях по статусам: ожидает подтверждения, подтверждено, отклонено.  
- Получение списка вещей конкретного пользователя.  
- Поиск вещей по названию и описанию (частичное/нечувствительное к регистру).  
- Создание запросов на вещи, которых ещё нет в системе, и предложение вещей пользователями в ответ на такие запросы.

## 🏗 Архитектура  
- Сервис управления вещами, бронированиями и запросами.   
- База данных PostgreSQL для хранения бизнес-данных.  
- Используются JPA/Hibernate для ORM.
